# MAAMEN — חוקי עבודה ל-Claude Code

תקציר סעיף 0 של תוכנית הבנייה (MAAMEN_BUILD_PLAN):

1. **אסור לשאול את המשתמש שאלות.** כל החלטה שלא מכוסה במסמך — קבל אותה לבד לפי
   עקרון "הפשוט ביותר שעובד", ותעד אותה ב-`DECISIONS.md` (תאריך, החלטה, נימוק
   בשורה אחת).
2. **בנה לפי סדר השלבים בסעיף 16 בלבד.** אין לעבור שלב לפני שכל קריטריוני
   הקבלה שלו עוברים בטסטים אוטומטיים.
3. **כל שלב מסתיים ב:** טסטים ירוקים (pytest), commit עם הודעה באנגלית,
   ועדכון `PROGRESS.md` (מה הושלם, מה הבא).
4. **MOCK FIRST:** כל אינטגרציה חיצונית (Green API, Anthropic, OpenAI,
   ElevenLabs) חייבת שכבת mock מלאה. כל הפיתוח והטסטים רצים במצב
   `MOCK_MODE=true` בלי אף מפתח אמיתי. מפתחות אמיתיים נכנסים רק ב-deploy.
5. **אסור להרחיב scope.** כל מה שבסעיף 17 ("לא בונים") — לא בונים, גם אם נראה
   מתבקש.
6. **סביבת פיתוח Windows.** כל הסקריפטים חייבים לרוץ גם ב-Windows וגם ב-Linux
   (Railway). אין להשתמש ב-bash-only פקודות בסקריפטים; להשתמש ב-Python לכל
   אוטומציה.
7. **שפת קוד, הערות, שמות: אנגלית.** כל טקסט שפונה למשתמש הסופי: עברית בלבד.
8. אם טסט נכשל 3 פעמים ברצף על אותה בעיה — פשט את הפיצ'ר (הורד תחכום) במקום
   להילחם. תעד ב-`DECISIONS.md`.
